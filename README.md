# 课程笔记分享库

本仓库是课程笔记的分享副本，包含两个目录：

- `课程笔记/` —— 各科课程笔记
- `复习提纲/` —— 各科复习提纲
- `assets/` —— 笔记中引用的图片附件

## 如何使用（仅阅读）

本仓库为**只读分享**，请勿向本仓库提交任何修改，你的改动不会被接受。

### 方式一：直接在线浏览
在 GitHub 网页上点击对应 `.md` 文件即可阅读。

### 方式二：用 Obsidian 打开（推荐，可看双链和图谱）

1. 安装 [Git](https://git-scm.com/downloads) 和 [Obsidian](https://obsidian.md/)
2. 克隆仓库到本地：
   ```bash
   git clone <本仓库地址> 课程笔记
   ```
3. 打开 Obsidian → 「打开文件夹作为库」→ 选择刚克隆下来的 `课程笔记` 文件夹
4. 即可浏览笔记，双链、图谱、图片均正常显示

### 更新到最新内容
进入克隆下来的目录，执行：
```bash
git pull
```
