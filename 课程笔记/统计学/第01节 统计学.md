## 一、统计与数据的基本概念（导论）

### 1. 什么是统计学

- **统计学**：收集、处理、分析、解释数据并从数据中得出结论的科学
- **描述统计**：研究数据收集、处理、汇总、图表描述、概括与分析——描述数据特征、找出基本规律（含搜集、整理、展示、描述性分析）
- **推断统计**：利用样本数据推断总体特征——对总体作出推断（含参数估计、假设检验）

### 2. 统计数据的类型（三种角度）

| 角度 | 类型 | 要点 |
| --- | --- | --- |
| 计量尺度 | **分类数据** | 只能归于某一类别的非数字型数据；分无序分类、有序分类 |
|  | **数值数据** | 按数字尺度测量的观察值；分离散数据、连续数据 |
| 收集方法 | **观测数据** | 通过调查或观测收集、无人为控制；社会经济数据几乎都是 |
|  | **实验数据** | 在实验中控制实验对象而收集；自然科学数据大多为 |
| 时间状况 | **截面数据** | 相同或近似相同时间点上收集；描述某一时刻的情况 |
|  | **时间序列数据** | 不同时间上收集；描述随时间变化的情况 |

### 3. 基本概念

- **总体 / 样本**：总体 = 所研究全部个体（数据）的集合（分有限、无限总体）；样本 = 从总体抽取的一部分元素，其数目称为**样本容量**
- **参数 vs 统计量**：参数描述**总体**特征（总体均值 μ、标准差 σ、总体比例 π，用希腊字母）；统计量描述**样本**特征、由样本数据计算（样本均值 x̄、标准差 s、样本比例 p，用小写英文字母）
- **变量**：说明现象某种特征的概念，其具体表现称为**变量值**（数据）；分**分类变量 / 数值变量**，数值变量又分**离散变量 / 连续变量**

### 4. 统计的误用（提醒）

- 不好的样本或过小的样本、误导性图表、局部描述、故意曲解——看统计数据先警惕这几类问题

## 二、数据收集

### 1. 问卷设计的要点

以"中华牙膏"调查为例，好的问卷要能同时回答 **信用情况、销量情况、偏好情况、优势之处** 四个目标。

**关键原则：**

- **筛选题**：如"是否用过中华牙膏"——没用过的人提供不了真实信息，要先筛掉
- **量化要与经验吻合**：如"一个月用几支牙膏"这种频次问题，被访者往往算不清（就像问"一学期去几次图书馆"，不如问"一周去几次"）
- **选项要完整**：列举品牌时先看销量排行，把主流品牌列上，份额不足 5% 的归入"其他"
- **问什么答什么**：回答要直接回应对方的问题，不要答非所问（"你结婚了吗？"—"我 40 多岁了"其实没回答问题）
- **正反面都能问**：既可以问"你会选什么"，也可以问"你为什么不选"

### 2. 用 AI 辅助设计问卷

- 建议用 **工作模式**（比对话模式更专业，可申请免费试用）
- 明确告诉 AI 目标（如"我只要五道题，用于问卷设计"），问法不同答案不同
- AI 的产出不逊于无经验的同学，可让它多design 几道再挑选
- 注意：AI 版可能只考虑"题面"，而好的设计还要考虑**后续量化可行性**（有得分才能算比例、做排序）

### 3. 社交媒体调研

**难度最大，但有条件可用：**

- **前提：对象要有"自带热度"**。中华牙膏在社交媒体上热度低，信息分散，如同大海捞针
- **样本有偏**：抖音/小红书用户 ≠ 全部消费者。购买牙膏的多是"负责家庭采购"的群体，未必是线上用户
- **评论数据有偏**：为拿"金豆"奖励而评论的人、懒得打字的人，都可能扭曲结果

**成功的正面案例——新式茶饮推新品：**

1. 抓取社交媒体（笔记、话题、弹幕、转发）中的**高频词**（如"椰子汁""低糖"）
2. 做**词频统计**，高频词即热点
3. 对高频词做**组合**，形成候选新品
4. 交专业人士品尝评价（线下环节，社交媒体做不到）
5. 找**意见领袖（大V）** 转发造势，带火产品

> 电商"牙膏热销榜"参考数据（8 月周期）：波普专研 1.69 亿、参半 9400 万、usmile 7200 万、俊小白 7200 万、舒客 5200 万。

## 三、数据预处理

### 1. 数据审核

| 数据类型 | 审核重点 |
| --- | --- |
| **二手数据** | 覆盖范围是否匹配研究对象、时效性是否够（如调查"抬头率"不能用十年前数据）；还要问：**谁收集的（可信度）、什么目的、如何收集的**；**成本低，能用优先用** |
| **一手数据** | 缺失值、逻辑错误（年龄填 200 岁、收入填 1 万亿） |

### 2. 数据筛选

- 用是非题筛选，如只保留"用过中华牙膏"的问卷
- 或用数值条件筛选，如"统计学成绩等于 75 分""四门课都 > 70 分"
- Excel 和各类统计软件都能做

### 3. 数据排序

- 快速了解数据的**基本范围**（最小值、最大值）
- 观察哪个数值**出现次数特别多**，即代表性数值
- 还能帮助**检查纠错**、为重新归类或分组提供方便
- 类别数据排序：字母型习惯升序；汉字可按拼音或笔画

## 四、分类思想——十分重要的能力

### 案例："西游记师徒四人怎么分类？"

同学们的答案：

| 分类标准 | 结果 |
| --- | --- |
| 是否为人 | 人（唐僧）vs 动物（孙悟空等）——但孙悟空是石头里蹦出来的，定义不精确 |
| 改为"非人" | 人 vs 非人 ✓ 更严谨 |
| 人妖之分 | 孙悟空、猪八戒又不能简单归为妖 |
| 衣着 | 暴露型（白龙马）vs 保守型 |
| 战斗力 | 几乎为零（白龙马、唐僧）/ 中等（沙僧、猪八戒）/ 顶级（孙悟空） |
| 颜值、财富等级 | 也可以分 |

**核心启示：**

- 定义必须**精确、无歧义**，不能靠"感觉"（做学术要有依据）
- 分类角度不同 → 研究问题不同 → 商业计划走向不同
- **"怎么分才与别人不同"就是创新点**
- 例：颜值研究能上顶刊（基金经理脸型与业绩、CEO 身高与企业绩效），虽争议大
- 例：比亚迪 vs 欣旺达，可从**规模**（大 / 小）、**业务**（多元 / 单一）或**生态链**（闭环 / 开源，类比苹果 vs 安卓）来分

## 五、分类数据的描述

### 1. 频数与频率

- **频数**：某类别出现的次数
- **频率**：该次数占总次数的比重
- **频数分布表**：把各类别及其频数列成表格；按变量个数分**简单频数表 / 二维列联表 / 多维列联表**

**应用**：人口年龄结构（少儿 / 成年 / 老年）——关注成年人口比例，即"人口红利"；"红利消失"就是劳动人口比例变小。人口结构影响商业决策（如雅培奶粉退出中国市场）。

### 2. 案例：小卖部饮料销售

观察 50 位买饮料的顾客，记录两个变量：**性别** + **饮料类型**（都是分类数据）。

- 原始数据太乱，肉眼看不出规律 → 做**频数统计**
- 结果：**碳酸饮料**最受欢迎
- 做**二维交叉分析**（性别 × 饮料类型）：

> ⚠️ **关键教训**：数据客观 ≠ 结论正确。"女性爱碳酸饮料、男性爱绿茶"与经验不符，要追问原因：
> - 校区女生本来就多（抽样环境偏差）
> - 买饮料是给自己还是给别人（购买动机）
> - **绝对数不能直接比**！男女总数不同（22 vs 28），必须先化成**比例**再比

### 3. 常用图形

| 图型 | 用途 |
| --- | --- |
| **条形图** | 单变量对比 / 复合对比（分组、堆积） |
| **饼图** | 各品类占比（实心） |
| **环形图** | 多个样本（组）的构成比较：内环 / 外环分别代表不同样本 |
| **帕累托图** | 累计排序，验证 **二八定律**（80% 利润来自 20% 商品 / 客户） |

## 六、数值型数据的描述

### 1. 分组

**分组要"恰到好处"：**

- 太粗（如只分"及格 / 不及格"、或"2500 以下 / 以上"）→ 无区分度
- 太细（每 2 分一组）→ 组数过多，很多组没有数据
- 参考经验分组：60–70 及格、70–80 中等、80–90 良好、90+ 优秀

**分组步骤（以销量数据为例）：**

1. **审核**异常值（如某天 5000 台、某天 0 台 → 剔除或单独考虑）
2. **排序**，找出最小值和最大值（如 141 与 237，相差 96）
3. **确定组数**：一般不少于 5 组、不多于 15 组（5≤K≤15），本例数据较多，分 10 组
4. **确定组距**：(最大 − 最小) ÷ 组数 ≈ 9.6，优先取 **5 或 10 的倍数**（数学处理更方便）→ 组距取 10；最高频区间（如 170–180 有 27 天）即代表性数值

**开口组**：最小 / 最大组用"XX 以下""XX 以上"，可把极端值包进去，避免为异常值再单独分组。

**注意"上组限不在内"**：用 Excel 直方图做频数表时，恰好等于某组上限的值要算入下一组——接收区域要输入比上限略小的数。

### 2. 图形

- **直方图**：分组数据的分布形态
- **箱线图（箱形图）**：看中位数（平均水平）+ 箱长（四分位差）+ 须长（内围栏内的最值）+ 异常值（**超出内围栏**，即距上下四分位数 **1.5 × 四分位差**，图中单独标出；超 **3 × 四分位差**为极值）
- **散点图**：判断两变量关系（无关 / 正相关 / 负相关 / 抛物线）；多变量用**散点图矩阵**，对角线放直方图
- **雷达图**：把多维数据投影到二维。案例——四直辖市各消费大类支出对比：上海在多数维度最高（食品烟酒、居住、交通通信、教育文化娱乐、其他用品 5 项），北京在衣着、生活用品及服务、医疗保健 3 项最高，重庆全维度最低；居住维度差异最大（上海约为重庆的 4 倍）；北京人均食品烟酒支出（8064.9）低于天津（8647.5）

> **制图规范**：能用图就用图；设计尽可能**简洁**、避免不必要的修饰；**不要夸张**（图形大体保持 4:3，过长或过高都会歪曲数据）；图和表都要有**标题**，标题写明时间、地点、内容（**3W**）；系统性论文中图表要**编号**。

## 七、集中趋势（平均数）

> 老师强调：这里讲的是**集中趋势**——强调数据的**聚集性**，别只当成"求平均数"；它是一类统计量的总称，平均数、中位数、众数、四分位数、几何平均数都在其中。

### 1. 数值平均数

| 类型 | 定义 | 特点 |
| --- | --- | --- |
| **算术平均数** | 所有数值之和 ÷ 个数 | 最常用，但对极端值敏感 |
| **加权平均数** | 组中值 × 该组频数，再汇总 ÷ 总数 | 分组降维后使用，可得"大致平均数" |

> 分组后的加权平均与原始数据精确平均可能接近，也可能差异很大（老师自己的调查中 430 vs 470）。

### 2. 位置平均数

| 类型 | 定义 | 适用 / 特点 |
| --- | --- | --- |
| **中位数** | 排序后处于中间位置的数值 | 对极端值稳定，适合收入、支出等天然不均衡的数据；企业招聘报"中位数工资"更真实 |
| **四分位数** | QL（下四分位，25%）、QU（上四分位，75%） | 中位数概念的延伸；四分位差 = QU − QL |
| **众数** | 出现频率最高的数值 | 分类数据也能用（如性别、专业）；可能不唯一或不存在 |

> 中位数要求**能排序**；众数不要求排序，因此适用于定性数据（如"满意度"这种有序分类）。

### 3. 几何平均数

- 适用场景：总量的形式是**连乘**而非加和
- 典型例：**转化率**（每步转化率相乘 = 总转化率）、平均利率、复利计算
- 计算：n 个数连乘后开 n 次方
- 限制：数据中出现**零值或负值**时不宜计算几何平均数

### 4. 三者对比

| 指标 | 适用场合 | 缺点 |
| --- | --- | --- |
| 算术平均数 | 最广泛、最易理解 | 分类数据不能用；有极端值时效果差 |
| 中位数 | 分布不对称、有极端值时 | 需能排序 |
| 众数 | 各类数据都能用（只要有集中趋势） | 可能不唯一，或不存在 |

## 八、离散程度

> 数据 {10, 20, 30, 40, 50} 是"集中"还是"离散"？两位同学给出两种思路：① 找一个中心做对比；② 用最大最小值算极差。

### 1. 极差（全距）

- 定义：最大值 − 最小值（分组数据用最大组上限 − 最小组下限）
- 优点：计算简单
- 缺点：受极端值影响大，反映不出中间数据的差异

### 2. 四分位差（四分位距 IQR）

- 定义：QU − QL
- 反映**中间 50% 数据**的离散程度；IQR 越小，说明中位数对一组数据的代表性越强

### 3. 平均差

- 各数值与**平均数**的离差（绝对值）的平均数
- 缺点：绝对值在数学上不好处理（要分情况讨论）

### 4. 方差与标准差 ⭐

- **方差**：各数值与平均数离差**平方**的平均数——最标准的离散度量
- **标准差**：方差的**开方**——量纲与原始数据一致，描述波动程度非常好
- **样本方差为何除以 n−1**：样本均值构成一个约束条件，自由度少 1，用 n−1 才是**无偏估计**

### 5. 离散系数（CV）

- 定义：**标准差 ÷ 平均数**（相对离散程度）
- 用途：当两组数据的**量纲或水平差异大**时，不能直接比标准差，要比相对值
- 类比：乒乓球直径误差 1mm vs 地月距离误差 50m——绝对误差后者大，相对误差前者大

**项目投资决策案例：**

| 项目 | 期望报酬率 | 风险（标准差） | 离散系数 |
| --- | --- | --- | --- |
| A | 60% | 15% | 15 ÷ 60 = **0.25** |
| B | 8% | 3% | 3 ÷ 8 = **0.375** |

> A 的**相对风险更小**，应选 A。投资决策要"固定一个因素，再看另一个因素"；离散系数就是消除报酬水平差异的**标准化手段**。

### 6. 标准分数（z 分数）

- 定义：某数据与平均数的**离差 ÷ 标准差**——表示它与平均数"相差多少个标准差"
- 用途：测度每个数值在整组数据中的**相对位置**；Excel 可用【STANDARDIZE】函数
- 课件例：450 元的标准分数为 −0.3990，即比平均低约 0.4 个标准差

### 7. 经验法则与切比雪夫不等式

- **经验法则**（数据**对称分布**时）：约 68% 在平均数 ±1σ 内、约 95% 在 ±2σ 内、约 99% 在 ±3σ 内；**±3σ 之外**在统计上称为离群点
- **切比雪夫不等式**（**任意分布**，给出"至少"的下界）：至少有 1 − 1/k² 的数据落在 ±kσ 内——k = 2 → 75%，k = 3 → 89%，k = 4 → 94%

### 8. 投资组合与相关性

> 1000 元，两种股票：高风险科技股 vs 稳定银行股，怎么配？

关键不是比例，而是**相关性**：

- 若两类股票同涨同跌（高度相关），怎么配都没用，无法对冲
- 只有**不相关**的资产组合，才能分散风险
- "不要把鸡蛋放在同一辆车上"——关联性决定了能否分担风险

## 九、分布形状的度量（偏度 / 峰度）

### 1. 偏度系数

- 测度数据分布的**不对称性**：对称分布 = 0
- **正值右偏**（长尾在右侧）、**负值左偏**（长尾在左侧）；|偏度| > 1 严重偏斜、0.5 ~ 1 中等、< 0.5 轻微
- 课件例：网购金额为**轻微右偏**

### 2. 峰度系数

- 测度数据分布**峰值的高低**，与标准正态分布比较
- = 0 与正态相当；> 0 **尖峰分布**（数据相对集中）；< 0 **扁平分布**（数据相对分散）

## 十、老师的提醒

- 二手数据优先于一手数据（成本低，先看覆盖范围和时效）
- 图表用得好，是职场沟通最有力的工具
- 数据要和认知对照：冲突可能意味着**新发现**，也可能意味着**数据有偏或方法粗糙**
- 培养**分类思维**，从基础数据开始训练
