## 一、描述性统计收尾（承接第 01 节）

> 第 01 节讲了"数据长什么样"，本节先把**集中趋势 / 离散程度**讲透，再收尾**分布形态**。

### 1. 波动性就是风险

- 两个项目**平均回报都是 18%**：A 波动 10%（有时 23%、有时 12%），B 波动只有 3%
- 回报一样时，理性投资者选**波动小**的 → **波动（标准差 / 方差）就是风险的度量**
- **股债跷跷板**：无风险的长期国债收益率一旦走高（如 $>5\%$），资金就从股市流向债市，股市因此承压——无风险收益都这么高，何必冒险
- **不可能三角**：一项资产不可能同时做到**高回报、低风险、高流动性**，最多满足其中两个

### 2. 离散程度的度量（两类）

| 类型 | 指标 | 特点 |
| --- | --- | --- |
| **粗糙型**（取两个点） | 全距（极差）、四分位差 | 只用两个点，信息利用少 |
| **精细型**（与中心比较） | 平均差、**方差 / 标准差** | 把所有数据与认可的中心比较，看平均差异 |

> 实证研究中**需要数据有一定波动**：若标准差几乎为 0，审稿人会质疑"数据没有变化，怎么去找自变量对因变量的影响"，这样的研究无意义。

### 3. 离散系数（变异系数 $\mathrm{CV}$）—— 跨总体比较

- 当两个总体的**均值不同**（如 A 回报 60%、B 回报 8%）时，不能直接比标准差，要剔除均值的量纲影响
- **$\mathrm{CV} = s / \bar{x}$**（标准差 ÷ 均值）
- 例：A（$15\% \div 60\% =$ **0.25**）、B（$3\% \div 8\% =$ **0.375**）→ $\mathrm{CV}$ 小者相对变异小 → **选 A**

### 4. 相关性：投资组合能否对冲风险的钥匙

- 把资金分散到"不同"股票，**关键看它们之间是否相关**
- **正相关**（同涨同跌）→ 分散也没用，无法对冲
- 只有**负相关**的资产组合才能对冲风险
- 类比："不要把所有鸡蛋放在**同一辆车**上"——放不同篮子但同车，车翻了照样全碎

### 5. 标准化与标准分数（$Z$ 分数）

- **为什么要标准化**：多维数据各维度**量纲、数值量级不同**（如点击率几千万 vs 转化率百分数），直接放进模型，量级大的会"天然"起主导作用，需消除这种影响
- **标准分**：$Z = (x_i - \bar{x}) / s$，即（数值 − 平均数）÷ 标准差 —— 描述数据在分布中的**相对位置**（距均值几个标准差）
- **对称分布的经验法则**：约 68% 落在 $\mu \pm \sigma$、约 95% 落在 $\pm 2\sigma$、约 99% 落在 $\pm 3\sigma$ 内
- **应用**：高考标准分——**只改变数值大小，不改变排名**（把分数压缩到 $-3 \sim 3$ 之间）
- 例：标准分 $+1.7$ → 高于平均约 1.7 个标准差；$-0.5$ → 低于平均半个标准差

### 6. 分布形态：偏度与峰度

**偏度（Skewness）**

- 描述分布的**不对称性**；对称分布偏度 $= 0$
- 本质是**中心矩**的概念：$k$ 阶中心矩中，$k = 1$ 必为 0、$k = 2$ 必 $> 0$，**对称分布**的奇次矩会互相抵消
- 因此取**最小的、不为零的矩——三阶中心矩**作为不对称的标志
- **$> 0$ 右偏**（存在极大值，长尾在右）；**$< 0$ 左偏**（存在极小值，长尾在左）
- 偏斜严重时，很多经典统计原理不再适用 → 需做**数据变换**（如取对数、对数加一）让分布更集中

**峰度（Kurtosis）**

- 描述分布**峰值高低**，与**标准正态分布**比较（正态峰度 $= 0$）
- 用**四阶中心矩**度量
- **$> 0$ 尖峰分布**（数据相对集中）；**$< 0$ 平峰分布**（数据相对分散）

> 课件例：30 人网购金额——偏度略 $> 0$（轻微**右偏**），峰度 $< 0$（略有**扁平**）。

### 7. 描述性统计的实证应用（李清源老师文章）

- 研究主题：**环境规制 + 政府补贴 → 企业绿色创新**（《经济研究》/《管理世界》级别，1600+ 家企业）
- **均值要卡在经验认知内**：绿色创新均值若接近 0 则无研究意义；若异常大（如 35）则要怀疑计量方法有误
- **中位数 $= 0$** 意味着：一千多家企业里，有一半以上**完全没有绿色创新**
- **分位数**（10% / 90%）反映分布两端；**标准差大** → 差异足够大，研究才有价值
- 收费、补贴等变量变异程度相对小（同行业政策往往"一视同仁"，补贴常以**虚拟变量**形式表现）
- **描述统计是实证分析的第一步**——先让读者理解数据的范围、波动与合理性

**显著性星号（读文献必知）**

| 符号    | 含义                 |
| ----- | ------------------ |
| `***` | $p < 0.01$（99% 可靠） |
| `**`  | $p < 0.05$（95% 可靠） |
| `*`   | $p < 0.1$（90% 可靠）  |
| 无星    | 通常被视为不可接受（可靠性太低）   |

## 二、推断性统计总论

| | 描述性统计 | 推断性统计 |
| --- | --- | --- |
| 做什么 | 手上有什么数据，就整理、展示、计算各类指标 | 用**样本**去推断**总体**的特征 |
| 态度 | 描述"它是什么样" | 由少量样本推断总体 |
| 例子 | 算样本的均值、标准差 | 用 150 个大学生推断全体大学生的支持率 |

- **总体的特征是唯一、固定的；样本的特征是随机、可变的**（换一批样本，均值就变了）
- 现实困境：经费有限，**通常只抽一次样**，却要用这一次的随机结果去推断唯一固定的总体
- 核心难点：**如何用一个随机可变的样本，去可靠地推断唯一固定的总体**
- 统计的哲学：输入不确定 → 输出也不确定，但用**可靠性（如 95%）**来限定可接受性

## 三、统计量

### 1. 定义

- **统计量** = 样本 $x_1, x_2, \dots, x_n$ 的一个函数 $T(x_1, x_2, \dots, x_n)$
- **硬性要求：函数里不能包含任何未知的总体参数**
  - $\bar{x} = (x_1 + \dots + x_n) / n$ → **是**统计量
  - 若写成"减去总体均值 $\mu$"→ **不是**统计量（含未知参数 $\mu$）

### 2. 常用统计量

- **样本均值 $\bar{x}$**、**样本比例 $p$**、**样本方差 $s^2$**（以**样本均值**为中心计算，不涉及总体参数）
- 还可构造：样本变异系数（$s / \bar{x}$）、$k$ 阶原点矩 / 中心矩、偏度系数、峰度系数

### 3. 好统计量的标准

- 抽样推断**信息量必然有损失**，因此要**尽量让统计量涵盖更多信息**
  - $\bar{x}$ 涵盖 $n$ 个样本信息，优于只取两个样本的 $(x_1 + x_2) / 2$
- 优良统计量（$\bar{x}$、$p$、$s^2$）**可从理论上证明是总体参数的无偏估计量**，因此被广泛使用

### 4. 统计量是随机变量

- 样本每抽一次就变一次 → 作为样本函数的统计量也随之变化 → **统计量是随机变量，不是固定值**

### 5. 估计量与估计值

| 概念 | 含义 | 记号 |
| --- | --- | --- |
| **估计量** | 用来估计总体参数的统计量（随机变量） | $\hat{\theta}$（读作"$\theta$ 帽"） |
| **估计值** | 把某次具体样本代入估计量算出的**具体数值** | 一个确定的数 |
| **参数** | 总体的特征（唯一、固定） | 希腊字母 $\theta$（$\mu$、$\sigma$、$\pi$） |

> 例：以本班为样本估计"广工学生 618 平均花费"——样本均值 $\bar{x}$ 是**估计量**，本班算出的 680 元是**估计值**。

## 四、抽样分布

- **骰子例**：总体 {1,2,3,4,5,6}，取样本量 2，把所有可能的样本都列出并计算样本均值 $\bar{x}$
- 单个 $\bar{x}$ 会随样本变化，但把**所有可能的 $\bar{x}$ 取值及其出现次数**画出来，会形成一个新的分布
- **抽样分布 = 样本统计量的概率分布**（这里是"样本均值的抽样分布"）
- **意义**：虽然单个统计量在波动，但**抽样分布具有稳定的特征**——正是这个稳定性，搭起了"样本统计量"与"总体参数"之间的桥梁，成为推断的基石

## 五、中心极限定理（CLT）

### 1. 版本一：总体服从正态分布

若总体 $X \sim N(\mu,\ \sigma^2)$，则样本均值

$$ \bar{X} \sim N\left(\mu,\ \frac{\sigma^2}{n}\right) $$

- **$E(\bar{X}) = \mu$**：样本均值的均值 = 总体均值
- **$\sigma_{\bar{X}} = \sigma / \sqrt{n}$**：样本均值的标准差（**标准误**），随 $n$ 增大而变小

### 2. 版本二：任意总体 + 大样本

不管总体是什么分布，只要**样本量 $n$ 足够大**（经验上 $n \ge 30$），就有

$$ \bar{X} \ \dot{\sim}\ N\left(\mu,\ \frac{\sigma^2}{n}\right) $$

- **条件大幅放宽**（不再要求总体正态），代价是需要大样本——而"多抽样"是容易实现的条件
- 直观理解：无论总体多奇怪，只要样本足够大，**样本均值的分布都会趋于聚集并接近正态**
- 这是推断统计**最核心的基石**

## 六、三大抽样分布

> 不同的统计量服从不同的抽样分布；常见有 $\chi^2$、$t$、$F$ 三种。

### 1. 卡方分布 $\chi^2$

- **来源**：标准正态变量的平方 $Z^2$ 服从自由度 1 的 $\chi^2$ 分布；若干独立 $\chi^2$ 之和仍为 $\chi^2$
- **可加性**：$\chi^2(n_1) + \chi^2(n_2) = \chi^2(n_1 + n_2)$
- **与样本方差的关系**：**样本方差 $s^2$ 对应自由度 $n-1$ 的卡方分布**（用于对样本方差做推断）
- 形状：**右偏**，自由度越大越趋近正态分布

### 2. t 分布（学生氏分布）

- **来源**：当总体 **$\sigma$ 未知**、只能用**样本标准差 $s$** 替代时，$\bar{X}$ 不再服从正态分布，而服从 **$t$ 分布**
- 形状：比正态分布**更平坦、尾部更厚**（信息更"松散"）
- 常用于**小样本、$\sigma$ 未知**的情形

### 3. F 分布

- **来源**：**两个卡方分布之比**
- 形状：类似 $\chi^2$，略带右偏
- **用途**：**方差分析**中分解方差时，分子 / 分母都是"均方（方差）结构"，其比服从 $F$ 分布 → 检验方差比

## 七、参数估计

### 1. 什么是参数估计

- 总体参数未知、全体统计成本过高 → 抽样本，构造**估计量**，用**样本统计量估计总体参数**
- 样本量一般要满足 CLT 要求（$n \ge 30$）

### 2. 点估计 vs 区间估计

| 方法 | 做法 | 缺点 |
| --- | --- | --- |
| **点估计** | 直接用估计值替代总体参数（如"618 人均花 680 元"） | 简单，但**给不出误差**，无法评估可靠性 → 实际几乎不用 |
| **区间估计** | 以点估计为中心，± 一个**可容忍的误差**，形成区间 | 能同时表达"估计值 + 误差"，实用 |

> **射击比赛类比**：正中靶心最好，但很难每次打中；于是"只要落在中心附近的一个圈内就算得分"——以击中的点为中心画一个可容忍的圈（区间），这个圈就是**置信区间**。

### 3. 三个核心概念

| 概念 | 含义 |
| --- | --- |
| **置信区间** | 以点估计为中心、附加可容忍误差构成的区间 |
| **置信水平 $1-\alpha$** | 所有可能样本区间中，**能包含总体参数真值**的比例（如 95%） |
| **风险值 $\alpha$** | 区间**不包含**真值的比例；$\alpha$ 与 $1-\alpha$ 互补（和为 1） |

**⚠️ 置信水平的正确理解**

- **不是**"某个具体区间包含 $\mu$ 的概率是 95%"
- 因为 **$\mu$ 是固定值、样本一旦抽出区间也固定**，两个固定值之间谈不上概率
- 正确理解：**在所有可能的样本所构成的区间中，有 95% 能包含 $\mu$**（如 20 个区间里 19 个包含真值 → 95%）

### 4. 误差、置信水平与抽样分布的三角关系

- 误差要求（$\Delta$）越严 → 区间越窄 → 能包含真值的区间越少 → **置信水平越低**
- 放宽误差 → 区间变宽 → 置信水平越高，但估计"精度"下降
- **$\Delta$ 与 $1-\alpha$ 之间要权衡**；通常 **$\Delta$（精度要求）是外生给定的**（如"误差不超过 100 元""失业率调查误差不超过 3%"）

### 5. 常用 Z 值（标准正态分位数 $z_{\alpha/2}$）

| 置信水平 $1-\alpha$ | $\alpha$ | $z_{\alpha/2}$ |
| --- | --- | --- |
| 90% | 0.10 | **1.645** |
| 95% | 0.05 | **1.96** |
| 99% | 0.01 | **2.58** |

> 来源于经验法则：$\pm \sigma \approx 68\%$、$\pm 1.96\sigma \approx 95\%$、$\pm 2.58\sigma \approx 99\%$。

### 6. 总体均值的置信区间（$\sigma$ 已知 / 大样本）

$$ \bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} $$

- 若 **$\sigma$ 未知**：用**样本标准差 $s$** 替代即可（大样本下仍近似成立）

### 7. 案例 A：食品包装重量

- 条件：标准重量 100 g；总体 $\sigma = 10$ g；抽取 $n = 25$ 袋；要求 95% 置信水平
- 查表 $z_{\alpha/2} = 1.96$；样本均值 $\bar{x} = 105.36$
- 误差 $= 1.96 \times 10 / \sqrt{25} =$ **3.92**
- **置信区间 $= 105.36 \pm 3.92 \to (101.44, 109.28)$**（课件精确值；课上老师口述约 101~109 克）
- 解读：下限都已超过 100 g → 对消费者是"良心产品"（灌多了），但对厂家是**成本被拉高**（不合规但偏利多）

### 8. 案例 B：保险产品年龄定位

- 背景：保险产品类型与投保人年龄密切相关，用已知投保人年龄推断目标年龄段
- 条件：$n = 36$（大样本）；总体分布、$\sigma$ 均未知；要求 90% 置信水平
- 查表 $z_{\alpha/2} = 1.645$；点估计 $\bar{x} = 39.5$ 岁；样本标准差 $s = 7.77$ 岁
- 误差 $= 1.645 \times 7.77 / \sqrt{36} \approx$ **2.13**
- **置信区间 $\approx 39.5 \pm 2.1 \to [37.4, 41.6]$ 岁**
- **商业启示**：区间**并非越精确越好**。此例区间只有 5 岁左右，虽精确却太窄，反而不利于营销拓客；商业场景中可**适当放宽置信水平**，换来更宽的区间以便执行

## 八、估计量的性质

| 性质 | 含义 | 直观 |
| --- | --- | --- |
| **无偏性** | $E(\hat{\theta}) = \theta$：估计量取值的平均等于真值 | 所有点估计"均匀散布"在真值周围 |
| **有效性** | 同为无偏时，**方差（标准差）更小**者更有效 | 估计值更紧密地聚在真值附近 |
| **一致性** | $n \to \infty$ 时，$\hat{\theta}$ 趋于真值 $\theta$ | 样本越大越准 |

> **取舍问题**（无标准答案）：一个**无偏但波动大**的估计量 $\hat{\theta}_1$，与一个**有偏但误差小**的估计量 $\hat{\theta}_2$，谁更好取决于需求——追求"平均意义上无偏"选 $\hat{\theta}_1$，完全不能容忍大误差则选 $\hat{\theta}_2$。

## 九、案例延伸与老师的提醒

- **双十一 / 618 消费调查**（中国人民大学 2020 年调查，教材导读数据）：女性平均消费金额 95% 置信区间为 **1063.39 ~ 1501.99 元**，男性为 **496.93 ~ 814.15 元**（课上老师口述约 1063 / 500~800）
- **移动支付与消费**：电子货币弱化了"付钱的痛感"，可能诱发**过度消费**；其背后常由**信贷**支撑，衍生**信贷风险**
- **信贷工具提醒**：花呗、京东白条等本质是信贷支付方式，需有防范意识（曾有学生被骗 20 余万元）
- **统计是不确定的科学**：输入不确定、输出亦不确定，用**可靠性程度（如 $>90\%$）**来框定可接受性——这正是置信水平的意义
- **考试提醒**：老师明确说**一定会考一道参数估计（置信区间）的题**，务必会写完整过程

**构建置信区间的通用思路**

1. 以样本点估计为中心
2. 加减一个可容忍的误差
3. 由置信水平查表得到 $z_{\alpha/2}$，误差 $= z_{\alpha/2} \times$（抽样分布的标准差）
4. 大样本 / $\sigma$ 未知时，用 $s$ 替代 $\sigma$，$\sigma_{\bar{X}} = s / \sqrt{n}$

## 十、课件补充（课堂未展开，供复习参考）

> 课件（贾俊平《统计学》）第 6、7 章内容比课堂讲授更全，以下几块课上未展开，列出供期末复习时对照：

- **总体比例的区间估计**：$p \pm z_{\alpha/2}\sqrt{p(1-p)/n}$（大样本）
- **总体方差的区间估计**：用 $\chi^2$ 分布，自由度 $n-1$
- **两个总体参数的区间估计**（7.3）：两均值之差（独立大样本 / 小样本方差相等·不等）、匹配样本、两比例之差、两方差比（$F$ 分布）
- **样本量的确定**（7.4）：估计均值时 $n = z_{\alpha/2}^2 \sigma^2 / E^2$；估计比例时 $n = z_{\alpha/2}^2 \pi(1-\pi) / E^2$（$E$ 为希望的估计误差）
