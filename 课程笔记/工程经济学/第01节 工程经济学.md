# 第01节 工程经济学

> 本节为导论课，主要讲**课程性质与考证前景**、**什么是工程经济**、**工程经济的六大原则**、**工程项目设计过程**。核心结论：本课 30% 是技术、70% 是管理，与建造师 / 造价师考证高度关联。

## 概要

| 板块 | 要点 |
| --- | --- |
| 课程与考证 | 建造师 / 造价师 / 监理工程师、挂靠行情、评标专家 |
| 什么是工程经济 | 成本更低、利润更高；兼顾社会责任 |
| 教材 | 清华大学出版社英文影印版（西方主流教材） |

| 研究与研究对象 | 政府 / 企业 / 公益组织；目标、环境、后果 |

## 一、课程性质与考核方式

### 平时与期末

- **平时分占 50%**：作业必须亲自做一遍；主动发言每次加 A，加满 3 次以上平时分基本接近满分（被点名不算，答对答错都算）
- **期末为闭卷 B 卷**：5–6 个大题（无小题），全英文题目
- 第 7 次课会划重点题型；期末考**同类型题换数字**，故平时作业必须掌握
- 第 8 次课直接考试（不上课）
- ⚠️ **给分看重步骤**：只写答案最多给辛苦分 1 分；写清计算思路即使算错也能拿 5 分以上。**每节课务必带草稿纸，把每一步写出来**

### 课程演进名称（考点常识）

| 阶段 / 地域 | 名称 |
| --- | --- |
| 西方早期（铁路选址） | 铁路选址的经济理论 |
| 西方后续 | 财务工程 → 行业投资项目的经济分析 → **工程经济** |
| 前苏联 / 中国 | 技术经济（强调技术性） |
| 日本 | 经济工程（翻译习惯，实为工程经济） |

### 教材

- 采用**清华大学出版社英文影印版**，哈佛、麻省理工等工程管理专业通用
- 用该教材可考美国 **FE（预备工程师）**→ 实践 4–5 年 → **PE（专业工程师）**
- 国内清华、上海交大、西安理工等少数高校可用英文版考试

### 考证方向

- **一级建造师 / 一级造价师**是主要方向；本课覆盖考证教材约一半内容，历年真题 70% 以上练过
- 本课难度**高于**考证，期末能过 70 分，考证难度不高
- 考证全是选择题（80 题：60 单选 + 20 多选），2/3 靠背、1/3 靠计算
- 相关资格证还有：注册咨询工程师、房地产估价师、房地产经济师、资产评估师
- 建造师 / 造价师每年 9 月 7–8 号考试

> **关于"挂证"（老师如实说明的现实）**：报名机构可代办工作证明，考过后会有中介联系挂靠。行情约：建造师 1.5 万/年、市政方向再加 0.5–2 万、机电方向 4–5 万、若连同身份证挂靠可达 4–50 万。**风险提示：出安全事故要担责**，国家正在打击，价格逐年下降。
>
> **评标专家**：有资格证可申请注册，评标半天 400 元 / 一天 800 元起。项目评标需 3 名以上专家，名额较多。

### 为什么需要资格证

- 项目评标三大文件：**基础文件、商务文件、技术文件**
- 基础文件硬性要求：公司需有本科以上学历者、持一级资格证者若干人——**没资格证项目根本不会给你**
- 中小企业为过门槛会**租赁资格证**，形成产业链

## 二、什么是工程经济

### 通俗定义

> **"别人花两块钱才能做成的事，你花一块钱就能做好"** —— 一门艺术，精华在于**比别人成本更低、利润更高**。

### 学术定义

运用**自然科学和数学方法**，在工程实践中有效利用材料、装备等资源，达到**利益最大化**，并能**造福人类**。

### 社会责任

- 西方教材**从始至终强调社会责任**；国内教材较少涉及
- **2008 年起**中国企业想进世界 500 强，被要求提供**社会责任报告**（"少这一块"），汶川地震、三聚氰胺事件是导火索
- 项目管理培养目标与国际认证挂钩，也要求有社会责任

## 三、工程经济的六大原则 ⭐

### 原则一：必须有多个方案（多方案比选）

> 向老板汇报时**不要只给一个方案**（那是"填空题"，老板很累）；应给出 A、B、C 三套方案 + 个人推荐 + 理由，让老板做**选择题**。这才是项目经理该有的角色。

### 原则二：比较各方案优劣（选最佳）

**案例——广工大建大学城校区，该卖掉哪个校区？**

| 校区 | 情况 | 决策 |
| --- | --- | --- |
| 东风路 | 市中心，帮老师落户，地位重要 | 保留 |
| 番禺 | 原香港龙辉电子厂地块，政府免费给但**只能办学、不能商用** | 保留 |
| 龙洞 | 周围全是二本三本，自身是唯一一本，"鹤立鸡群" | 保留 |
| **五山** | 被华工、华农、华师 985/211 包围，**放大劣势**，且地价贵 | **卖掉**（卖给广东外语艺术职业学院） |

> 龙辉电子厂老板**缺乏可持续观点**：危机时逃回香港，抛弃社会责任，工人拉起横幅讨薪，最终政府出面解决。

### 原则三：使用统一的评价观点

**案例——评标争议**：某次评软件项目技术方案，三种做法（拍图盖章 / 技术手册盖章 / 全部盖章）专家看法不一，最后统一为**"只认企业实际应用情况（真实使用截图+盖章）"**。故需请 3 名以上专家，对争议点达成**统一原则**。

### 原则四：使用统一的评价单位 / 标准

- 评价指标（如 NPV、PC、AC）要一致
- 投资时间不同时，须用**资金时间价值**折算到同一时点（年初 P 或年末 F）
- **重要结论：投资越晚越好**（同样金额折现到年初会变小，占便宜）——选择题常用此思路直接选对

### 原则五：考虑所有相关评价指标

- 中西方评价标准不同：国内工程还须考虑**立国立民**（政治、民生），不只是收益成本
- **案例——奥运会 / 亚运会**：
  - 北京奥运会：举国体制，不考虑收益只看国威
  - 香港（霍英东家族推动）：立法会 2/3 反对，认为看不到收益、只带来 60 亿成本和不便
  - 广州亚运会：**折中**——先不管收益，只考虑节约成本：大学城贷款免还、租用高校体育馆宿舍、大学生当免费义工、硬性摊派学生当查奥会观众
  - 唯独暨南大学校长先拒绝建校区，后被迫在番禺建"大学城二期"，被师生痛骂
- **基建选择**：工程经济说"公路/铁路/高铁只做一个就够"（利润最大化），但中国考虑民生会全覆盖（如拉萨也有公交地铁共享单车）

### 原则六：考虑风险与不确定性 ⭐（期末大题 + 考证重点）

- 投标书最后必须写**突发状况的应对方案**，否则叫"不完整"，扣分 → 这叫**闭环管理**
- AI 一键生成的应对方案会被识破，直接扣分
- 两大方法：**平衡分析法、敏感性分析法**
- **案例——龙洞校区的兴衰**：经济上行时 MPA/MBA 二战三战都难考，一个班扩到八个班；疫情后生源骤降只剩一个班；今年改为**网络面试快速发放录取通知**（不给思考时间），生源大幅回升

## 四、工程项目设计过程

1. **识别问题** → 找到投资决策良机（如响应政策做新能源、芯片）
2. **发展可行方案** → 找出所有可行方案
3. **比较收益与现金支出** → 相互比较
4. **选择合适标准** → 依标准比选

### 案例：房地产投资的前置条件

投资房地产需要满足以下**三个条件之一**：

1. **资金雄厚**（如温州商人高价买煤矿，但为省钱牺牲安全设施，最终被国家叫停私人煤矿）
2. **政治背景 / 政府关系**（如南沙区公务员下海，最终因行贿被抓，靠当污点证人才出狱）
3. **本地人**（靠宗族、面子关系低价拿地，如敏捷地产）

> 以上都不具备，就做**围绕大企业的配套业务**——照样能赚钱。

### 综合案例：万科 vs 华康（1996 年）

**背景**：王石 1984 年创立万科，当时"什么赚钱做什么"（日本录像机贸易），1992 年放开房地产后，万科聚焦**"只做中档城市民居"**（少做公寓/别墅/商场）。

**华康的处境**：做建材贸易、装修、家具、铝合金、拉链刺绣，**都打不过本地/成熟产业链**。

**同学的优秀答案**（本班综合思维强）：
- 砍掉不相关业务，聚焦**地产配套 + 商业物业**（有经验可深耕）
- 聚焦**物业管理**（有基础，深圳发展带来空间）
- 做**施工 / 装修配套**
- 做**餐饮**（有饭店基础 + 深圳人口增长）

**结论**：不做超越能力的业务（房地产需三个前置条件，华康都没有），而是做**围绕大企业的配套服务**，发挥自身核心能力。

> 类比：不会造电话手表，但可以造**挂绳、贴膜**；或在工厂旁开**沙县小吃**。**清楚自己能做什么、不能做什么。**

## 五、技术经济研究的对象

### 1. 活动主体

| 主体 | 职能 / 案例 |
| --- | --- |
| **政府** | 主导大型市政工程（如"再造古城"：山西大同、河南开封），政府没钱由中央拨款，层层发包。市政工程方向挂证费长期 2–2.5 万以上 |
| **企业** | 项目建设主力；评标可能内部勾结（如清华举报中国电信评标不公；学校物业"换公司不换老板"） |
| **公益组织** | 小额繁琐项目（图书馆、儿童治疗室、心理辅导室）；中山大学最先开设社工管理专业，后因含金量低、收入低而被叫停 |

### 2. 目标不一致

| 主体 | 目标 |
| --- | --- |
| **政府** | 解决就业、保护环境、民众平安幸福 |
| **企业** | 利润最大化、品牌效益最大化 |

> 为平衡两者，企业裁员话术不断"美化"：阿里"社会需要你"、腾讯"你被优化了"、京东"你被毕业了"、字节"你被狼性了"。企业招应届生多为拿政府补贴，试用期后即"毕业"。也有企业搞"40 岁现象"。

### 3. 环境因素

- **自然环境 / 物质材料**：如德国公司在中东建药厂承诺用本地建材，实际仍从德国进口，被控欺诈
- **经济环境**：房地产高价的链条中，地方政府卖地是重要一环（土地越卖越贵）；房地产下行后地方财政紧张（如广东河源市部分公务员半年发不出工资）

### 4. 经济评估的国家差异

**案例——非洲建医院**：西方坚持建"卓然立于西方城市的现代化医院"，结果因电力不足、医生不愿下乡而**从未投入使用**。落后国家发现中国"按当地国情提供低技术低成本建设"反而更合适 → 这是"一带一路"的博弈结果。

> 启发：外派越南、老挝、缅甸等国家，**海外补贴是国内同职位工资的 3–4 倍**，攒钱且有海外经历利于升值。

### 5. 方案后果（积极 / 消极）

**案例——缅甸密松水电站**：前期投入数亿，眼看建成，却因**克钦邦独立军**抗议（称掠夺资源、污染环境）而停工至今。教训：**不能只做政府层面工作，要深入当地调研**（类似后来的电信诈骗问题）。

## 六、课堂选择题选讲

### 1. 机械施工时间（多项选择）

**必须消耗的工作时间**包括：
- ✅ **有效工作时间**（正常负荷 + 降低负荷）
- ✅ **不可避免的无负荷工作时间**（如午休、吃饭）
- ✅ **不可避免的中断时间**
- ❌ 多余工作时间、施工造成的中断（应筛除）

### 2. 综合测试题：周末客户报修怎么办？

某经理周末接电话，客户设备出故障，但员工都下班了。选项：A 下周处理 / B 经理亲自去 / C 告诉主管经理 / D 告诉值班经理安排值班人员处理。

- **国企 / 内地企业**倾向选 A
- **广东 / 大部分企业**倾向选 **D**（值班经理本就是应对突发事件的）
- 小公司可能选 B（展示合作诚意，且员工身兼数职、能力全面）

> 没有标准答案，考察**情境下的综合判断**。因正确率太低，此题已不再给本科生用。

## 七、老师的目标规划建议（题外话但重要）

**哈佛大学 25 年跟踪研究**（关于人生目标对成就的影响）：

| 人群比例 | 目标状态 | 25 年后的结果 |
| --- | --- | --- |
| ~30% | **没有目标** | 生活在社会底层，抱怨且不参加同学会 |
| 60% | **目标模糊** | 社会中层，工作稳定但无特别成就 |
| ~10% | **清晰短期目标** | 不断实现小目标 → 企业精英、项目经理 |
| 3% | **清晰长期目标** | 最顶尖的成功人士（如一路本硕博留校当老师） |

> 启示：读书期间要规划——成绩、实习、考证。本课与职业规划关联度高，不只是通过考试。
