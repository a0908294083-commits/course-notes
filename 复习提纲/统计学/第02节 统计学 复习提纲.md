# 第02节 统计学 复习提纲

> 来源：[[课程笔记/统计学/第02节 统计学]]（课堂录音整理）
> 说明：本文件为复习用精简版，随课程逐节补充；全部课程结束后整合为完整复习文件。
> 相关：[[统计学 公式速查]]｜[[统计学 概念卡片]]

## 本节主线

**描述性统计收尾**（波动/风险 → 离散系数 → 相关性 → 标准化 → 偏度峰度）**→ 推断统计总论 → 统计量 → 抽样分布 → 中心极限定理 → 三大分布 → 参数估计与置信区间 → 估计量性质**。

## 一、描述性统计收尾

- **波动性 = 风险**：两项目平均回报同为 18%，波动小（$\sigma$ 小）者更优
- **股债跷跷板**：无风险国债收益率↑ → 资金流出股市 → 股市承压
- **不可能三角**：高回报 / 低风险 / 高流动性，最多取其二
- 离散程度两类：**粗糙型**（全距、四分位差）· **精细型**（平均差、方差、标准差）

### 离散系数 $\mathrm{CV}$（跨总体比较）

- 均值不同的两个总体，不能直接比标准差 → **$\mathrm{CV} = s / \bar{x}$**（标准差 ÷ 均值）
- 必记例：A（$15\% / 60\% = 0.25$）< B（$3\% / 8\% = 0.375$）→ **选 A**

### 相关性

- 分散投资能否对冲，**关键看相关性**：正相关 → 无法对冲；**只有负相关才能对冲**
- 类比："不要把所有鸡蛋放在**同一辆车**上"

### 标准化与标准分 $Z$

- 多维数据量纲不同 → 必须**标准化**，否则量级大的维度主导模型
- **$Z = (x_i - \bar{x}) / s$**（数值 − 平均数，再 ÷ 标准差），表示距均值几个标准差
- **经验法则**（对称分布）：≈ 68% 在 $\pm\sigma$、95% 在 $\pm 2\sigma$、99% 在 $\pm 3\sigma$ 内
- 高考标准分：**只改数值大小，不改排名**

### 偏度与峰度

| 指标 | 度量 | 判读 |
| --- | --- | --- |
| **偏度** | 三阶中心矩 | $=0$ 对称；**$>0$ 右偏**（长尾在右）；**$<0$ 左偏**（长尾在左） |
| **峰度** | 四阶中心矩 | 与正态比：$=0$ 相当；**$>0$ 尖峰**（集中）；**$<0$ 平峰**（分散） |

> 提示：对称分布的奇次中心矩会抵消，故用**最小的非零矩（三阶）**标志不对称。

### 实证案例（李清源文章）

- 主题：环境规制 + 补贴 → 绿色创新；1600+ 企业
- 要点：**均值要卡在经验认知内**（近 0 无意义、过大可疑）；**中位数 $=0$** 说明过半企业无创新；标准差大 → 差异足够才有研究价值
- **显著性星号**：`***` $p<0.01$ ｜ `**` $p<0.05$ ｜ `*` $p<0.1$ ｜ 无星 = 通常不可接受

## 二、推断统计总论

- **描述统计**：手头数据 → 展示特征；**推断统计**：用**样本**推断**总体**
- **总体唯一固定；样本随机可变**；现实通常**只抽一次样**
- 核心难点：用随机可变的样本，可靠地推断唯一固定的总体

## 三、统计量

- 定义：样本 $x_1, \dots, x_n$ 的函数 $T(x_1, \dots, x_n)$，**不能含任何未知参数**（含 $\mu$ 就不是统计量）
- 常用：样本均值 $\bar{x}$、样本比例 $p$、样本方差 $s^2$（以**样本均值**为中心）
- 好统计量：**尽量多含样本信息**（$\bar{x}$ 优于 $(x_1+x_2)/2$）；可证为**无偏估计量**
- **统计量是随机变量**（样本变则变）
- **估计量 $\hat{\theta}$**（随机变量）vs **估计值**（代入具体样本得到的数）

## 四、抽样分布

- 骰子例：列出所有样本的 $\bar{x}$，其分布即**样本均值的抽样分布**
- **抽样分布 = 统计量的概率分布**；虽单个统计量在变，但**抽样分布有稳定特征** → 推断的基石

## 五、中心极限定理 ⭐

| 情形 | 结论 |
| --- | --- |
| 总体正态 $N(\mu, \sigma^2)$ | $\bar{X} \sim N(\mu,\ \sigma^2/n)$（精确） |
| 任意总体 + $n$ 足够大（$\ge 30$） | $\bar{X}$ **近似** $N(\mu,\ \sigma^2/n)$ |

- **$E(\bar{X}) = \mu$**；**$\sigma_{\bar{X}} = \sigma / \sqrt{n}$**（标准误，$n$ 越大越小）
- 条件放宽（不再要求总体正态），代价是"要足够大的样本"——容易实现

## 六、三大抽样分布

| 分布 | 来源 / 用途 | 要点 |
| --- | --- | --- |
| **$\chi^2$ 卡方** | 标准正态平方和；**样本方差的分布** | 自由度 **$n-1$**；**可加性**；右偏，$n$ 大 → 趋近正态 |
| **$t$ 分布** | **$\sigma$ 未知**、用 $s$ 替代时 $\bar{X}$ 的分布 | 比正态**平坦、尾厚**；小样本常用 |
| **$F$ 分布** | **两个 $\chi^2$ 之比** | 用于**方差分析**（检验方差比） |

## 七、参数估计 ⭐（必考大题）

- **点估计**：直接用估计值；简单但**给不出误差**，实际几乎不用
- **区间估计**：点估计 ± 可容忍误差 → 区间（射击比赛类比）

| 概念 | 含义 |
| --- | --- |
| **置信区间** | 点估计为中心的区间 |
| **置信水平 $1-\alpha$** | 所有可能区间中**包含真值**的比例 |
| **风险值 $\alpha$** | 区间**不含**真值的比例（$\alpha + (1-\alpha) = 1$） |

**⚠️ 置信水平的正确理解**：不是"某个区间含 $\mu$ 的概率"，而是"**所有可能样本的区间中，有 $1-\alpha$ 比例包含 $\mu$**"（$\mu$ 固定、区间随机）。

**误差与置信水平的权衡**：误差要求越严 → 区间越窄 → 置信水平越低；通常 **$\Delta$（精度）外生给定**。

### 常用 Z 值与置信区间公式

| 置信水平 | 90% | 95% | 99% |
| --- | --- | --- | --- |
| **$z_{\alpha/2}$** | 1.645 | 1.96 | 2.58 |

$$ \bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} \qquad(\sigma\ \text{未知时用}\ s\ \text{替代}) $$

### 必会例题

**① 食品包装**：$\sigma = 10$、$n = 25$、$\bar{x} = 105.36$、95% → 误差 $= 1.96 \times 10 / \sqrt{25} = 3.92$ → **(101.44, 109.28)**（下限已超 100：对消费者良心、对厂家成本高）

**② 保险年龄定位**：$n = 36$、90%、$\bar{x} = 39.5$、$s = 7.77$ → 误差 $= 1.645 \times 7.77 / \sqrt{36} \approx 2.1$ → **[37.4, 41.6] 岁**（商业上**区间并非越窄越好**，太窄不利营销，可适当放宽）

**构建置信区间的通用步骤**

1. 找样本点估计（$\bar{x}$）
2. 依置信水平查 $z_{\alpha/2}$
3. 算误差 $= z_{\alpha/2} \times \sigma / \sqrt{n}$（$\sigma$ 未知用 $s$）
4. 写区间 = 点估计 ± 误差

## 八、估计量的性质

| 性质 | 含义 |
| --- | --- |
| **无偏性** | $E(\hat{\theta}) = \theta$（平均等于真值） |
| **有效性** | 同为无偏时，**方差小者**更有效 |
| **一致性** | $n \to \infty$ 时 $\hat{\theta} \to \theta$ |

> 取舍无标准答案：**无偏但波动大** vs **有偏但误差小**，取决于需求。

## 九、易错与提醒

- **置信水平 ≠ 某区间含 $\mu$ 的概率**（$\mu$ 与区间都固定，无概率可言）
- **点估计给不出误差**，不能用于正式推断
- **显著性**：星越多越可靠；无星通常被拒绝
- 商业场景中**置信区间不是越精确越好**（太窄反而失去实用价值）
- 老师明确：**参数估计必考一道题**，要会写完整过程

| 两项目同为 18% 回报 | 波动 = 风险，选低波动 |
