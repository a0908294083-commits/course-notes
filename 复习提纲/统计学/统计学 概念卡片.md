# 统计学 概念卡片

> 用途：把每个核心概念做成一张"速记卡"——**一句话定义 + 要点 + 易错点**，考前快速过一遍。
> 配套：[[统计学 公式速查]]（算得快）｜本卡（想得清）
> 命名规则：卡片号可按主题检索；随课程推进补充。

## 一、总论

### №01 统计学 · 描述统计 vs 推断统计

- **一句话**：描述统计"把手上数据说清楚"，推断统计"用样本猜总体"。
- **要点**：描述统计 = 收集 / 整理 / 展示 / 概括；推断统计 = 参数估计 + 假设检验。
- **易错**：别把"算样本均值"当推断——算出样本特征是描述，拿它去推总体才是推断。

### №02 总体 / 样本 · 参数 / 统计量

- **一句话**：总体唯一固定，样本随机可变；参数描述总体（希腊字母），统计量描述样本（拉丁字母）。
- **要点**：$\mu$、$\sigma$、$\pi$ 是参数；$\bar{x}$、$s$、$p$ 是统计量；样本中元素个数 = 样本容量 $n$。
- **易错**：$\mu$ 是固定的未知数，$\bar{x}$ 是变化的随机变量——这是理解置信区间的关键。

### №03 统计量

- **一句话**：统计量是**样本的函数**，且**不能含任何未知参数**。
- **要点**：$\bar{x}$ 是统计量；$(x_i - \mu)$ 就不是（含未知 $\mu$）。统计量是随机变量。
- **易错**：把"含 $\mu$ 的式子"当统计量；忽略"统计量随样本变化"这一随机的本质。

## 二、刻画数据

### №04 集中趋势

- **一句话**：一组数据向中心聚集的程度，代表值有平均数、中位数、众数、四分位数、几何平均数。
- **要点**：算术 / 加权平均（数值平均），中位数 / 众数 / 四分位数（位置平均）。
- **易错**：别把"集中趋势"窄化成"求平均数"——它是一类指标的总称。

### №05 中位数

- **一句话**：排序后处于中间位置的值。
- **要点**：对极端值稳健，适合收入、支出等天然不均衡的数据。
- **易错**：中位数**要求数据能排序**；偶数个数据取中间两数的平均。

### №06 众数

- **一句话**：出现频率最高的数值。
- **要点**：**分类数据也能用**；可能不唯一，也可能不存在。
- **易错**：以为众数一定要"存在且唯一"。

### №07 几何平均数

- **一句话**：$n$ 个数连乘后开 $n$ 次方。
- **要点**：适用于**连乘**场景——转化率、平均利率、复利。
- **易错**：数据含 **0 或负值**时不宜计算。

### №08 离散程度：极差 / 四分位差

- **一句话**：极差 $= \max - \min$；四分位差 $\mathrm{IQR} = Q_U - Q_L$。
- **要点**：极差粗糙、易受极端值影响；$\mathrm{IQR}$ 反映**中间 50%** 的离散程度。
- **易错**：用极差代表整体波动，忽略中间数据的差异。

### №09 方差 / 标准差

- **一句话**：方差 = 离差平方的平均；标准差 = 方差开方。
- **要点**：标准差量纲与原始数据一致，最常用的波动度量。
- **易错**：**样本方差分母是 $n-1$**（无偏），总体方差分母是 $N$。

### №10 离散系数 CV

- **一句话**：$\mathrm{CV} = s / \bar{x}$，即标准差 ÷ 均值，衡量**相对**离散程度。
- **要点**：当两个总体**均值不同**（量纲 / 水平差异大）时，比 $\mathrm{CV}$ 而非标准差。
- **易错**：均值相同或接近时用标准差即可；$\mathrm{CV}$ 无单位。

### №11 标准分数 Z

- **一句话**：$Z = (x_i - \bar{x}) / s$，即（数值 − 平均数）÷ 标准差，表示"距均值几个标准差"。
- **要点**：测度数值在分布中的相对位置；多维数据须先标准化。
- **易错**：标准化**只改数值大小，不改排名**；$Z$ 是无量纲的。

### №12 经验法则

- **一句话**：**对称 / 正态**分布下，约 68% / 95% / 99% 落在 $\pm \sigma$ / $\pm 2\sigma$ / $\pm 3\sigma$。
- **要点**：$\pm 3\sigma$ 之外常视为离群点。
- **易错**：它**只适用于对称分布**——分布偏斜时要用切比雪夫。

### №13 切比雪夫不等式

- **一句话**：**任意分布**下，至少有 $1 - \frac{1}{k^2}$ 的数据落在 $\pm k\sigma$ 内。
- **要点**：给出**下界（至少）**；$k=2 \to 75\%$、$k=3 \to 89\%$、$k=4 \to 94\%$。
- **易错**：与经验法则混淆——经验法则精确但要求对称，切比雪夫普适但只是下界。

### №14 偏度

- **一句话**：描述分布的**不对称性**，本质是三阶中心矩。
- **要点**：$=0$ 对称；$>0$ **右偏**（长尾在右）；$<0$ **左偏**（长尾在左）。
- **易错**：方向记反（"右偏"指长尾 / 极大值在右）；偏斜严重时经典统计原理不再适用。

### №15 峰度

- **一句话**：描述分布相对于**标准正态**的尖峭 / 扁平程度，用四阶中心矩。
- **要点**：$=0$ 相当；$>0$ **尖峰**（集中）；$<0$ **平峰**（分散）。
- **易错**：峰度是"与正态比"，不是绝对高度。

## 三、推断统计

### №16 估计量 vs 估计值

- **一句话**：估计量是**统计量**（随机变量，带帽 $\hat{\theta}$）；估计值是代入样本后的**具体数**。
- **要点**：$\bar{x}$ 是估计量；算出"680 元"是估计值。
- **易错**：把两者混为一谈；参数用希腊字母，估计量加帽。

### №17 抽样分布

- **一句话**：**统计量的概率分布**，是连接"样本统计量"与"总体参数"的桥梁。
- **要点**：单个统计量在变，但抽样分布**稳定**——推断的基石。
- **易错**：与"数据本身的分布"混淆（横轴是 $\bar{x}$ 而非 $x$）。

### №18 中心极限定理 ⭐

- **一句话**：无论总体什么分布，只要 **$n$ 足够大**，样本均值 $\bar{X}$ 近似服从正态分布。
- **要点**：$E(\bar{X}) = \mu$；$\sigma_{\bar{X}} = \sigma / \sqrt{n}$；总体正态时结论精确成立。
- **易错**：忘了"大样本"前提；忘了标准差是 **$\sigma / \sqrt{n}$** 而非 $\sigma$。

### №19 标准误

- **一句话**：样本统计量的标准差，衡量"每次抽样估计值的波动"。
- **要点**：$\sigma_{\bar{X}} = \sigma / \sqrt{n}$，$n$ 越大标准误越小（估计越稳）。
- **易错**：与"标准差（数据的波动）"混淆——标准误描述的是**估计量的波动**。

### №20 卡方分布 χ²

- **一句话**：标准正态变量的平方和构成的分布。
- **要点**：样本方差对应自由度 $n-1$ 的 $\chi^2$；有**可加性**；右偏，$n$ 大趋近正态。
- **易错**：自由度记错（是 $n-1$ 不是 $n$）。

### №21 t 分布

- **一句话**：**$\sigma$ 未知**、用样本标准差 $s$ 替代时，$\bar{X}$ 服从的分布。
- **要点**：比正态**平坦、尾部厚**；小样本 + $\sigma$ 未知时的标配。
- **易错**：$\sigma$ 已知时仍用正态，不该用 $t$。

### №22 F 分布

- **一句话**：**两个卡方分布之比**。
- **要点**：用于**方差分析**（比较方差 / 均方）。
- **易错**：与 $\chi^2$ 混淆；记住它是"两个 $\chi^2$ 的比"。

### №23 点估计 vs 区间估计

- **一句话**：点估计给一个数，区间估计给"数 ± 误差"。
- **要点**：点估计简单但**给不出误差**；区间估计能表达可靠性。
- **易错**：以为点估计够用——正式推断几乎都用区间。

### №24 置信区间

- **一句话**：以点估计为中心、加减可容忍误差构成的区间。
- **要点**：$\bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}$；$\sigma$ 未知则用 $s$ 替代。
- **易错**：区间**不等于**"$\mu$ 有 95% 概率落在里面"（见 №25）。

### №25 置信水平 1 − α ⭐

- **一句话**：**所有可能样本区间中，包含参数真值的比例**。
- **要点**：90% → 1.645、95% → 1.96、99% → 2.58；$\alpha$ 是"不含真值"的比例。
- **易错**：**最经典的坑**——它不是"某具体区间含 $\mu$ 的概率"（$\mu$ 与区间都固定，谈概率无意义）。

### №26 无偏性 / 有效性 / 一致性

- **一句话**：好估计量的三个性质——**平均对（无偏）、波动小（有效）、样本大就准（一致）**。
- **要点**：无偏 $E(\hat{\theta}) = \theta$；有效看方差小；一致 $n \to \infty$ 收敛。
- **易错**：以为"无偏"就最好——有偏但方差小的估计量有时更实用（看需求）。

### №27 显著性星号

- **一句话**：回归结果里的星号标示统计显著程度。
- **要点**：`***` $p < 0.01$（99%）、`**` $p < 0.05$（95%）、`*` $p < 0.1$（90%）；无星通常不可接受。
- **易错**：把星多当"影响大"——星表示"可靠"，不表示"效应强"。
