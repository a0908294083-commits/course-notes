# 统计学 公式速查

> 用途：期末复习时**一页查到所有公式**。按主题分组，随课程推进持续补充。

> 符号：$x_i$ 为原始数据，$n$ 为样本量，$\bar{x}$ 为样本均值。

## 一、集中趋势（平均数）

| 指标 | 公式 | 备注 |
| --- | --- | --- |
| 算术平均数 | $\bar{x} = \frac{\sum x_i}{n}$ | 对极端值敏感 |
| 加权平均数 | $\bar{x} = \frac{\sum x_i f_i}{\sum f_i}$ | 分组：组中值 × 频数 |
| 中位数 | 排序后中间位置的值 | 需能排序；对极端值稳健 |
| 四分位数 | $Q_L$（25%）、$Q_U$（75%） | 中位数概念的延伸 |
| 四分位差 | $\mathrm{IQR} = Q_U - Q_L$ | 中间 50% 的离散程度 |
| 众数 | 出现频率最高的值 | 分类数据也能用 |
| 几何平均数 | $G = \sqrt[n]{x_1 x_2 \cdots x_n}$ | 连乘场景（转化率、平均利率）；含 0 / 负值不宜用 |

---

## 二、离散程度

| 指标 | 公式 | 备注 |
| --- | --- | --- |
| 极差（全距） | $R = \max - \min$ | 简单；受极端值影响大 |
| 平均差 | $\frac{\sum \lvert x_i - \bar{x} \rvert}{n}$ | 绝对值不好处理 |
| **总体方差** | $\sigma^2 = \frac{\sum (x_i - \mu)^2}{N}$ | 以**总体**均值为中心 |
| **样本方差** | $s^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}$ | 以**样本**均值为中心；除 $n-1$ 才无偏 |
| **标准差** | $\sigma = \sqrt{\sigma^2}$；$s = \sqrt{s^2}$ | 量纲与原始数据一致 |
| **离散系数** | $\mathrm{CV} = \frac{s}{\bar{x}}$（或 $\sigma / \mu$） | 跨总体、均值不同时比相对离散程度 |
| **标准分数** | $Z = \frac{x_i - \bar{x}}{s}$ | 距均值几个标准差；Excel: STANDARDIZE |

> ⚠️ **样本方差为什么除 $n-1$**：样本均值本身是一个约束，自由度少 1，用 $n-1$ 才是**无偏估计**。

## 三、分布形状

| 指标 | 本质 | 判读 |
| --- | --- | --- |
| **偏度** | 三阶中心矩 | $=0$ 对称；$>0$ **右偏**；$<0$ **左偏**；绝对值 > 1 严重、0.5~1 中等、< 0.5 轻微 |
| **峰度** | 四阶中心矩 | 与正态比：$=0$ 相当；$>0$ **尖峰**；$<0$ **平峰** |

- $k$ 阶中心矩：$\frac{\sum (x_i - \bar{x})^k}{n}$；$k=1$ 时恒为 0；$k=2$ 时恒 $>0$；**对称分布的奇次矩相抵消**

---

## 四、抽样分布与中心极限定理

| 结论 | 公式 |
| --- | --- |
| 样本均值的均值 | $E(\bar{X}) = \mu$ |
| 样本均值的标准误 | $\sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}$ |
| 样本均值的抽样分布 | $\bar{X} \sim N\left(\mu,\ \frac{\sigma^2}{n}\right)$（总体正态，或 $n \ge 30$ 近似） |
| 样本比例的标准误 | $\sigma_p = \sqrt{\frac{\pi(1-\pi)}{n}}$ |
| 样本均值标准化 | $Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}$ |

- **中心极限定理**：任意总体，只要 $n$ 足够大（$\ge 30$），$\bar{X}$ **近似服从正态分布**
- **卡方分布**：$\chi^2 = \sum Z^2$；样本方差对应自由度 $n-1$ 的 $\chi^2$；**可加性** $\chi^2(n_1) + \chi^2(n_2) = \chi^2(n_1 + n_2)$；$E(\chi^2) = n$、$D(\chi^2) = 2n$；变量值恒为正、右偏，$n$ 越大越趋近对称
- **t 分布**：$\sigma$ 未知、用 $s$ 替代时 $\bar{X}$ 服从 $t$ 分布；比正态分布平坦、尾部厚
- **F 分布**：两个 $\chi^2$ 分布之比；用于方差分析

## 五、参数估计（置信区间）⭐

### 总体均值 $\mu$ 的置信区间

$$ \bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} $$

- **$\sigma$ 已知 / 大样本**：直接用上式
- **$\sigma$ 未知**：用样本标准差 $s$ 替代 → $\bar{x} \pm z_{\alpha/2} \cdot \frac{s}{\sqrt{n}}$
- **误差（边际误差）**：$\Delta = z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}$

### 常用 Z 值（$z_{\alpha/2}$）

| 置信水平 $1-\alpha$ | $\alpha$ | $z_{\alpha/2}$ |
| --- | --- | --- |
| 90% | 0.10 | **1.645** |
| 95% | 0.05 | **1.96** |
| 99% | 0.01 | **2.58** |

### 经验法则与切比雪夫不等式

| 名称 | 适用 | 内容 |
| --- | --- | --- |
| **经验法则** | 对称 / 正态分布 | 约 68% 在 $\mu \pm \sigma$、95% 在 $\pm 2\sigma$、99% 在 $\pm 3\sigma$ 内 |
| **切比雪夫不等式** | **任意分布** | 至少 $1 - \frac{1}{k^2}$ 落在 $\mu \pm k\sigma$ 内（$k=2 \to 75\%$、$k=3 \to 89\%$、$k=4 \to 94\%$） |

### 估计量的性质

| 性质 | 公式表达 |
| --- | --- |
| 无偏性 | $E(\hat{\theta}) = \theta$ |
| 有效性 | 无偏前提下 $\mathrm{Var}(\hat{\theta})$ 越小越好 |
| 一致性 | $n \to \infty$ 时 $\hat{\theta} \to \theta$ |

## 七、课件补充公式（课堂未展开，考试可能涉及）

| 场景 | 公式 |
| --- | --- |
| **总体比例**的置信区间 | $p \pm z_{\alpha/2} \sqrt{\frac{p(1-p)}{n}}$ |
| **总体方差**的置信区间 | 用 $\chi^2$ 分布（自由度 $n-1$）：$\frac{(n-1)s^2}{\chi^2_{\alpha/2}} \le \sigma^2 \le \frac{(n-1)s^2}{\chi^2_{1-\alpha/2}}$ |
| **两个总体均值之差**（独立大样本） | $(\bar{x}_1 - \bar{x}_2) \pm z_{\alpha/2} \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}$ |
| **样本量**（估计均值） | $n = \frac{z_{\alpha/2}^2 \sigma^2}{E^2}$ |
| **样本量**（估计比例） | $n = \frac{z_{\alpha/2}^2 \pi(1-\pi)}{E^2}$（$\pi$ 未知时取 0.5，此时 $\pi(1-\pi)$ 最大） |

> 注：$\sigma$ 未知时一律用样本标准差 $s$ 替代；$E$ 为使用者事先确定的估计误差。
