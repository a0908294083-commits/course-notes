# 第01节 统计学 复习提纲

> 来源：[[课程笔记/统计学/第01节 统计学]]（课堂录音整理）
> 说明：本文件为复习用精简版，随课程逐节补充；全部课程结束后整合为完整复习文件。

## 本节主线

一条链条：**统计与数据基本概念 → 数据收集 → 数据预处理 → 分类数据描述 → 数值数据描述 → 概括性度量（集中趋势 / 离散程度 / 分布形状）**。

## 一、统计与数据的基本概念（导论）

- **统计学**：收集、处理、分析、解释数据并从中得出结论；**描述统计**（搜集 / 整理 / 展示 / 描述性分析）vs **推断统计**（参数估计、假设检验）
- **数据类型的三种分法**：计量尺度（分类数据 / 数值数据）· 收集方法（观测数据 / 实验数据）· 时间状况（截面数据 / 时间序列数据）
- **基本概念**：总体 / 样本（样本容量）；**参数**（描述总体：μ、σ、π）vs **统计量**（描述样本：x̄、s、p）；变量（分类 / 数值，离散 / 连续）
- **统计误用**：不好的样本或过小的样本、误导性图表、局部描述、故意曲解

## 二、数据收集

### 问卷设计要点

- **筛选题**先行（如"是否用过中华牙膏"）
- **量化要与经验吻合**：问"一周去几次图书馆"，不问"一学期去几次"
- **选项要完整**：主流品牌 + "其他"（份额不足 5% 归入）
- **正反面都能问**：会选什么 / 为什么不选；回答要问什么答什么

### AI 辅助设计

- 用**工作模式**；先明确目标（"只要五道题"）
- AI 可能忽略**后续量化可行性**（要有得分才能算比例、做排序）

### 社交媒体调研

- 前提：对象**自带热度**；注意样本偏差（线上用户 ≠ 消费者）、评论偏差
- 成功案例（新式茶饮）流程：抓高频词 → 词频统计 → 组合候选新品 → 线下品评 → 大V 造势

## 三、数据预处理

| 步骤 | 要点 |
| --- | --- |
| 审核 | 二手数据：覆盖范围、时效性 + 评估 5 问（谁 / 为何 / 如何 / 何时收集）（**成本低，优先用**）；一手数据：缺失值、逻辑错误 |
| 筛选 | 是非题筛选 / 数值条件筛选（如统计学成绩等于 75 分、四门课都 > 70 分） |
| 排序 | 看基本范围（min/max）、找出现次数特别多的值；还能查错、为分组提供方便 |

## 四、分类思想 ⭐

- 定义必须**精确、无歧义**（"西游记师徒分类"案例）
- **"怎么分才与别人不同"就是创新点**（如企业按规模 / 业务 / 生态链分类）

## 五、分类数据的描述

- 频数（次数）/ 频率（占比）；二维交叉表（性别 × 饮料类型案例）
- ⚠️ **绝对数不能直接比，要先化成比例再比**（男女总数不同：22 vs 28）
- 图形：条形图 / 饼图 / 环形图（多个样本构成对比：内环 / 外环代表不同样本）/ **帕累托图**（累计排序，验证二八定律）

## 六、数值数据的描述

- **分组**：组数一般 5≤K≤15；组距 =（max − min）÷ 组数，宜取 **5 或 10 的倍数**；太粗无区分度、太细没有数据；可用开口组包住极端值；Excel 直方图注意"**上组限不在内**"
- **图形**：直方图（分布形态）、箱线图（中位数 + 箱长 / 须长 + 异常值：**超出内围栏（距四分位数 1.5 × 四分位差）**单独标出，超 3 × 四分位差为极值）、散点图（关系判断，多变量用矩阵）、雷达图（多维投影）
- **制图规范**：能用图就用图；简洁、不夸张（图形约 4:3）；图表有标题（含 3W：时间 / 地点 / 内容）；论文中要编号

## 七、集中趋势（平均数 · 中位数 · 众数 · 四分位数 · 几何平均数）

| 指标    | 要点                              |
| ----- | ------------------------------- |
| 算术平均数 | 最常用；对极端值敏感                      |
| 加权平均数 | 分组后：组中值 × 频数，再汇总 ÷ 总数           |
| 中位数   | 对极端值稳定，适合收入 / 支出；**需能排序**       |
| 四分位数  | QL（25%）/ QU（75%）；四分位差 = QU − QL |
| 众数    | 出现频率最高；**分类数据也能用**；可能不唯一或不存在    |
| 几何平均数 | 连乘场景：转化率、平均利率、复利；含 0 或负值不宜计算                |

## 八、⭐ 离散程度

| 指标 | 要点 |
| --- | --- |
| 极差 | 简单；受极端值影响大，看不出中间差异 |
| 四分位差 IQR | = QU − QL；反映中间 50% 数据的离散程度 |
| 平均差 | 绝对值在数学上不好处理 |
| 方差 / 标准差 | 离差平方的平均；样本方差除 **n−1** 才是无偏估计 |
| **离散系数 CV** | = 标准差 ÷ 平均数；量纲 / 水平差异大时比相对风险 |
| 标准分数 | 离差 ÷ 标准差；测度相对位置（相差几个标准差） |
| 经验法则 | 对称分布：约 68% / 95% / 99% 在 ±1 / 2 / 3σ 内 |
| 切比雪夫不等式 | 任意分布：至少 1 − 1/k²（k=2/3/4 → 75% / 89% / 94%） |

**必会例题**：A 项目 60%、标准差 15% → CV = 0.25；B 项目 8%、标准差 3% → CV = 0.375 → **选 A**（相对风险更小）。

- 投资组合：关键不是比例，而是**相关性**——不相关的资产才能分散风险

## 九、分布形状（偏度 / 峰度）

- **偏度**：测不对称性；= 0 对称；> 0 **右偏**（长尾在右）、< 0 **左偏**；|偏度| > 1 严重、0.5 ~ 1 中等、< 0.5 轻微
- **峰度**：与标准正态分布比较；= 0 相当；> 0 **尖峰**（相对集中）、< 0 **扁平**（相对分散）

## 十、案例速查

| 案例 | 考点 |
| --- | --- |
| 中华牙膏问卷 | 问卷设计（筛选题、量化吻合经验） |
| 西游记分类 | 分类要精确无歧义；分类角度 = 创新点 |
| 小卖部饮料 | 绝对数不能直接比，先化比例 |
| 新式茶饮推新品 | 社交媒体调研全流程 |
| A / B 项目投资 | 离散系数比相对风险 |
| 1000 元股票组合 | 相关性决定能否分散风险 |
| 四直辖市消费支出 | 雷达图对比多维差异：上海多数维度最高、北京 3 项最高、重庆全维最低（居住差异最大） |

## 易错与提醒

- 数据客观 ≠ 结论正确；与认知冲突时，追问是**新发现**还是**数据有偏 / 方法粗糙**
- 二手数据优先于一手数据（成本低，先看覆盖范围和时效）
