# 第01节 工程经济学 复习提纲

> 来源：[[课程概要/工程经济学/第01节 工程经济学]]（课堂录音整理）

## 本节主线

导论课四块内容：**考核规则**（怎么拿分）→ **什么是工程经济**（定义）→ **六大原则**（核心考点）→ **项目设计过程与研究对象**（理解 + 案例）。老师定调：本课 30% 技术、70% 管理，与建造师 / 造价师考证高度挂钩。

## 一、考核规则（先记，直接影响拿分）

| 项目 | 规则 |
| --- | --- |
| 平时分 | 占 50%；主动发言每次加 A，满 3 次以上基本接近满分（被点名不算） |
| 期末 | 闭卷、全英文、5–6 个大题（无小题） |

## 二、必背概念

- **通俗定义**："别人花两块钱才能做成的事，你花一块钱就能做好"——成本更低、利润更高
- **学术定义**：运用自然科学和数学方法，有效利用材料、装备等资源，达到**利益最大化**并**造福人类**
- **社会责任**：西方教材从始至终强调；2008 年起进入世界 500 强的中国企业被要求提交社会责任报告
- **名称演变**：铁路选址经济理论 → 财务工程 → 行业投资项目经济分析 → **工程经济**；前苏联 / 中国称**技术经济**；日本称**经济工程**

## 三、⭐ 六大原则（核心考点，配案例记）

1. **必须有多个方案**——给老板 A/B/C 三套方案 + 推荐 + 理由，做"选择题"而不是"填空题"
2. **比较各方案优劣**——广工大案例：五山校区被 985/211 包围、放大劣势、地价贵 → 卖掉；龙洞校区"鹤立鸡群" → 保留
3. **统一评价观点**——评标争议由 3 名以上专家统一原则（如只认企业实际应用情况）
4. **统一评价单位 / 标准**——不同时点按**资金时间价值**折算；⭐ **投资越晚越好**（选择题常用思路）
5. **考虑所有相关评价指标**——国内还要考虑立国立民；案例：北京奥运（举国体制）vs 香港（2/3 反对）vs 广州亚运（折中：只节约成本）
6. **考虑风险与不确定性**（期末大题 + 考证重点）——投标书必须写突发应对方案（**闭环管理**）；两大方法：**平衡分析法、敏感性分析法**

## 四、项目设计过程

**识别问题 → 发展可行方案 → 比较收益与现金支出 → 选择合适标准 → 执行与监控**

- 房地产投资三前置条件（满足其一）：资金雄厚 / 政治背景 / 本地人
- 万科 vs 华康案例结论：做**围绕大企业的配套服务**，发挥核心能力，不做超越能力的业务

## 五、研究对象与案例速查

- 三大主体：**政府**（市政工程）、**企业**（利润最大化）、**公益组织**（小额繁琐项目）
- 目标不一致：政府要就业、环境、民众幸福；企业要利润、品牌

| 案例 | 考点 |
| --- | --- |
| 密松水电站停工（缅甸） | 不能只做政府层面工作，要深入当地调研 |
| 非洲建医院未投入使用 | 要按当地国情（低技术低成本）建设 |
| 龙洞校区生源兴衰 | 风险与不确定性（原则六） |

## 六、课堂例题要点

- 机械施工时间（多选题）：**必须消耗的时间** = 有效工作时间 + 不可避免的无负荷工作时间 + 不可避免的中断时间；"多余工作时间""施工造成的中断"要筛除
